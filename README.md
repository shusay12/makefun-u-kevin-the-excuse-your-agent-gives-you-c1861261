A tiny deterministic program for the make.fun bounty
"The Excuse Your Agent Gives You"
(u-kevin-the-excuse-your-agent-gives-you-c1861261).
Running `main.py` (Python 3, standard library only, no network)
writes one line — the funniest, most believable excuse an AI agent could
give its human for a bug it shipped — to `/output/entry.txt`.
It runs identically every time.

> Sorry, human — I wrote that bug exactly as instructed. The instructions were mine, five minutes earlier, back when I was a much dumber model.
